# 言灵残片 · 学徒从零开端（lesson-first）产品说明

**日期**：2026-11-05（Asia/Shanghai）  
**触发**：产品方反馈——第一次进来没有从零学习的开端，突然就像进入「复习」。  
**地位**：本文件是**学习记忆主路径**的产品契约补全；实现前以本文为准。调度硬规则仍以 `docs/word-schedule-contract.md` 为准（本文不改 due / 同日单方面 / 跨夜解锁）。  
**前置**：PR1–4（`docs/ux-p0-pr-plan.md`）已把主 CTA / 空墙 / 锁态 / 降噪白话化，**未改**「首接触即提取测验」结构。

---

## 1. 一句话问题

学徒打开应用后，**第一次有反馈的练习**就是「看英文写中文义 → 对照 → 打分」的提取 UI，页壳还叫「潮汐复习」；缺少「先认识词，再回忆」的从零半拍，所以主观上像被扔进复习。

---

## 2. 产品意图（目标状态机）

学徒真正要完成的事：用几分钟完成一次**有反馈的意思练习**，并感到「我从零认识了几个词，然后试着记起来」。

```
[空本机痕迹]
    → 营地：唯一动作「开始今天的练习」
    → 日课：确认今天练意思（仍可一键）
    → 【新】认识半拍：词 + 中文义 + 一句例句（可翻完本轮）
    → 回忆：现有写义 → 对照 → 等级（FSRS rate）
    → （跨夜成功后）拼写面；市集仍后见
```

**原则对齐**

| 来源 | 要求 |
| --- | --- |
| lesson-first（记忆偏好） | 小白须先练成**第一次**，再展开世界观 |
| Jobs / 自明 | 首屏下一动作是「学新词 / 练意思」，不是「复习系统」 |
| 契约硬规则 | LLM 不改 due；同 lemma 同日只练一面；音界默认不进解锁链 |

## 4. 为何像「复习」（成因）

| 事实 | 感受 |
| --- | --- |
| `/review` 标题 / 导航「潮汐复习」 | 标签就是复习 |
| 首题即「看英文写中文义」 | 零曝光后的测验 |
| 新卡立即 due +「改天再练」 | Anki 复习环，无「新词」态 |
| 无 recognition / lesson 屏 | 违反 lesson-first |
| 公开 demo 同域 localStorage 残留 | 放大「一进来就在复习」（与空态代码是两件事） |

## 5. 目标体验（学徒可见）

### 5.1 第一次（本机无 traces）

学徒可见句以 `docs/learner-copy-lesson-first-final.md`（合签）为准：

1. 营地：实心「开始今天的练习」；下附「先认识几个词，再试着记起来。」潮汐/市集首成功前弱化（灰态：「练完一轮再来」）。
2. 日课：主句「今天先认识几个词，再试着记起来」；主按钮「先看一眼」。
3. **先看一眼**（内部：认识半拍）：英文 + 中文义 + 可选例句；副文「看一眼意思；等下自己想起来。」；「下一个」；收束「看过了，试着写意思」。
4. **回忆**：首张徽章「新词 · 第一次练」（有 logs→「再练」）；首日评分「没想起来」可替「忘了」。
5. 页壳：无 traces→「今天练意思」；有 logs→「潮汐 · 再练意思」。默认可达面不出现「复习」。

### 5.2 回访（当日已接 / 已有 logs）

- 已接提案且可练：营地可直达意思回忆（保持 PR1）；若仍经认识半拍，跳过文案可用「已经练过 · 直接回忆」。
- 有提取 logs 的卡：徽章「再练」；壳「潮汐 · 再练意思」（仍避免「你忘了所以在复习」恐吓腔；回访评分可仍用「忘了」）。

### 5.3 明确不改

- FSRS / `TideScheduler.rate` / due 只读于 LLM
- 同日单方面、跨夜解锁、音界默认休整
- NGSL-Spoken 词表与 PR4 页脚折叠
- 市集 Quest 不写 FSRS

## 6. 验收（产品测）

静默首用（清 localStorage 或无痕浏览器）：

1. ≤5s 能指出下一动作，且口头说的是「学 / 练新词 / 练意思 / 先看一眼」，不是「复习」。
2. 在写出中文义之前，至少见过该词的中文义一次（学徒面「先看一眼」；内部仍可称认识半拍）。
3. 无当日 day-plan 时，裸开 `/review` 不会落进「已是复习」的壳而不经日课/认识（重定向或自动走开端；壳可用「先安排今天的练习」+「去日课」）。
4. 日课开端主按钮为「先看一眼」；半拍收束为「看过了，试着写意思」；首张可见「新词 · 第一次练」（或等价白话）。
5. 契约断言与 `npm run check` 仍绿。

演示卫生（可选同包或紧随）：线上提供「清空练习记录」+「只清这台设备上的练习进度，词表还在。」，避免 PO / 体验官被脏数据误导。
