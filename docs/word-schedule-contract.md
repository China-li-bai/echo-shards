# 言灵残片 · 单词调度契约（v1 · 证据改写后）

状态：已采纳为讨论定稿（2026-10-26）；音界与「恰好 N 次」为可实验参数。  
范围：仅单词陈述侧（形 / 义 / 音文字）；不含市集开口、流利、WTC。  
证据来源：深度挖掘与实践研究 2026-10-26 三缺口包（Barcroft TOPRA；Kim & Webb 2022；Rowland 2014 等）。

---

## 硬规则（证据支撑，默认不可关）

1. **同 lemma 同日只练一个方面**  
   对齐 TOPRA：形、义、映射争抢有限加工资源；同日多目标会互伤。  
   若同日多界 due 撞车：只出优先未完成界的一张，其余 due **顺延**；编排 / LLM **不得改 due**。

2. **该方面的练习必须是有反馈的主动提取**  
   回忆 / 产出（写出义、拼出形、写出音标串）优先于再认点选（Rowland：测试 > 再学；回忆 > 再认）。

3. **解锁「下一界」的时间条件：至少跨一个睡眠夜**  
   两次成功主动提取须落在不同日历日（Asia/Shanghai），中间至少隔一夜。  
   不支持「当天连对两次 = 可开下一界」。

4. **阅读 / 附带遭遇不替代系统词表调度**  
   附带有增益但效率不足以撑 NGSL 地板；潮汐仍是主轨。

## 可配置默认（可 A/B，非证据锁定）

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 方面顺序 | 义 → 形 → 音（文字） | TOPRA **不规定**顺序；仅作实验默认 |
| 跨日成功次数 N | 2 | 硬约束是「跨睡眠夜再成功」；N∈{1,2,3} 可调 |
| 单潮名额 | ≈5 个「方面·词」位 | 容量假设，不是 5 词 × 3 界 |
| 失败是否清零跨日计数 | 不清零 | 工程启发式；连续失败可暂停解锁至再次跨日成功 |
| 文字音标界 | **实验轨 / 默认不进解锁链** | 无 ASR 下「写出音标」对中文 EFL 缺直接试验；不宣称 = 会发音 |

## 解锁状态机（逻辑）

对每个 lemma 的每个方面 `aspect ∈ {meaning, form, phonology_text}`：

- `locked` → 未满足前置（顺序默认下：义无锁；形需义已 `unlocked_next`；音默认保持实验锁，或仅当开关打开且形已 `unlocked_next`）
- `active` → 已进入 ts-fsrs；按 due 出题
- `unlocked_next` → 本方面累计成功主动提取 ≥ N，且其中至少两次跨睡眠夜 → 允许按顺序打开下一界（音界受实验开关约束）

成功定义：该次卡片判定为正确的产出/回忆；再认正确默认**不计入** N（可另开实验）。

## 明确不做

- 不用「已掌握」关闭方面或整词  
- 不把搭配 / 词族 / 语用塞进本契约第一层  
- 不因日课勾选三界而同一天铸完
