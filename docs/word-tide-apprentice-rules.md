# 言灵残片 · 单词潮汐三界 · 学徒规则卡（v1）

来源：精通心理学的游戏设计大师 · 2026-10-26  
约束：遵守 `word-schedule-contract.md` 硬规则；练功台短句；禁止「已掌握 / 通关 / 学完」。

## 拍板摘要

1. 锁与跨夜：开炉 / 过今夜；禁止暗示当天连对可开界。
2. 撞车与音界关：各一句稀缺 / 休整，无政策辩白。
3. N 与实验旋钮：学徒默认不可见；音界若开须标明 ≠ 会开口。
4. 残片墙：共用「跨夜锻成」；亮灯 / 开界 / 远岸都是痕迹，不是成绩单。
