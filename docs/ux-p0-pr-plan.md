其它（营地世界观、市集、工坊、残片诗意）都是锦上添花，不能挡在第一次成功前面。

### PR1 范围（仅此先做）

**改**
1. 日课主按钮：`接过今日提案` → **`开始练意思`**（或等价：若已接过则「继续练意思」）。副文保留「同一个词今天只练一面…」。
2. 营地主按钮：`去日课` → **`开始今天的练习`**，点击后进入日课；若当日提案已接过且可练，则直达 `/review`（意思面）。
3. 冷启动（本地还无 day-plan / 未接提案）：打开 `/` 或首次进应用时，主卡只强调一个实心按钮；次要「去市集」降为文字链或首日隐藏。
4. 标题「今日提案」可保留作区名，但学徒主句与按钮必须是「练」不是「接提案」。

**不改**
- 调度契约、gate、N、音界默认不进链
- 市集/工坊业务逻辑（仅可降权入口，PR1 不做完整 progressive nav）
- 视觉品牌色（cream+teal）

**测**
- `npm run check`（或项目既有 test/typecheck/build）绿
- 手动/自动化：未接提案 → 点主按钮进入练习流并能看到意思题卡
- 文案断言：学徒默认可达面无「接过今日提案」字样
- 不引入 FSRS/lemma/aspect 等黑话回潮

### PR2 范围（PR1 合入后）

**改**
1. 「拼写残片墙」空态：删纯诗意唯一空态；白话说明「练过意思并隔夜后，痕迹会出现在这里」+ **可点次级按钮「先去练意思」**（链到 `/day` 或已接则意思 `/review`，与 PR1 主路径一致）。样式 outline/次要，不与营地主卡「开始今天的练习」同等抢戏。
2. 营地主卡：主 CTA 仍是实心「开始今天的练习」；步骤条弱化（字号/对比度/位置），不抢主按钮。

**不改**
- 调度契约、gate、N、音界；PR3 锁态；PR4 CEFR/页脚；品牌色；市集业务逻辑。

**测**
- `npm run check` 绿
- 空墙可见「先去练意思」+ 隔夜说明；无纯诗意唯一空态
- 营地仍只有一个实心主 CTA

**落地要点（本仓）**
- `form-shard-wall.tsx`：cold 空态通路 CTA；`page.tsx` 步骤条降权；`assert:pr2-empty-wall` 文案轻断言。

### PR3 范围（PR2 合入后）

**改**
1. 锁态 / 休整卡：只留 **一句** 原因（闸门旁注白话）；去掉旁注横幅 + 标题 + 副文同义三叠。
2. 实心主按钮「去练意思」：链到 `today-practice-href`（日课或已接则意思 `/review`）；「回日课」降为文字链。
3. 可练时闸门旁注仍可单独一行；锁/休整时旁注不与卡内原因重复。

**不改**
- 调度契约、gate/N、音界默认不进链；PR4 CEFR/页脚；品牌色；市集业务；PR1/PR2 主路径。

**测**
- `npm run check` 绿
- 锁/休整面可见唯一实心「去练意思」；无「现在只能看看…」等叠句；无开炉/只读黑话回潮

**落地要点（本仓）**
- `review-session.tsx`：`practiceBlocked` 卡只留一句 `gateNote` + 实心「去练意思」；`assert:pr3-lock-rest` 文案轻断言。

### PR4 范围（PR3 合入后）
