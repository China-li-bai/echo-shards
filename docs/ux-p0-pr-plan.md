### PR1 范围（仅此先做）

**改**
1. 日课主按钮：`接过今日提案` → **`开始练意思`**（或等价：若已接过则「继续练意思」）。副文保留「同一个词今天只练一面…」。
2. 营地主按钮：`去日课` → **`开始今天的练习`**，点击后进入日课；若当日提案已接过且可练，则直达 `/review`（意思面）。
3. 冷启动（本地还无 day-plan / 未接提案）：打开 `/` 或首次进应用时，主卡只强调一个实心按钮；次要「去市集」降为文字链或首日隐藏。
4. 标题「今日提案」可保留作区名，但学徒主句与按钮必须是「练」不是「接提案」。

**不改**
- 调度契约、gate、N、音界默认不进链
- 市集/工坊业务逻辑（仅可降权入口，PR1 不做完整 progressive nav）
- 视觉品牌色（cream+teal）

**测**
- `npm run check`（或项目既有 test/typecheck/build）绿
- 手动/自动化：未接提案 → 点主按钮进入练习流并能看到意思题卡
- 文案断言：学徒默认可达面无「接过今日提案」字样
- 不引入 FSRS/lemma/aspect 等黑话回潮
