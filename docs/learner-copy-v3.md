## 全站文案守则（3）

1. **学徒主文只说人话**：意思 / 拼写 / 读音；今天练 / 改天再练；还不能练 / 开练了 / 暂时不练。FSRS、due、lemma、aspect、NGSL 包路径、enrichment、eval、localStorage、load、只读、解锁按钮，一律不进主文。  
2. **同一事实说一次**：词表许可与「没有校对的中文义不显示」只在页脚；掌握/亮灯口径只在残片详情。  
3. **隐喻可以留，但要一秒懂**：过今夜＝隔夜再来；开炉＝开练了；休整＝暂时不练。搭建者说明默认折叠或移出学徒壳。
