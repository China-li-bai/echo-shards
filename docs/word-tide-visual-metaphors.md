# 言灵残片 · 单词潮汐三界 · 视觉隐喻（v1）

来源：精通美学并能自由应用在软件领域应用 · 2026-10-26  
约束：对齐 `word-schedule-contract.md` + `word-tide-apprentice-rules.md`；cream+teal 品牌不动；不碰 due 写入。

## 总则

- 锁 = 灰冷未开炉（非惩罚红叉）
- 亮 = 跨夜痕迹（非掌握奖章）
- 开炉改潮汐卡眉 / 可进态；墙只跟跨夜成功提取

## A 开炉

- 意象：炉口第一次亮起 = 新工位上线
- 表现：该界 realm 左边线 + 眉签；开炉瞬间眉签 fill ≈200ms 再退回描边
- 文案：「形界开炉」（义/音同理）
- 不与墙亮灯逻辑绑死

## B 休整 / 未开炉

- 意象：炉口盖着
- 表现：去饱和灰青、无红；旁注「未开炉 · 过今夜」或「音界工坊休整中」
- 点开只读、无解锁按钮；未开炉界不占墙灰砖

## C 残片亮 + 远岸

- 今日新亮：近景石感 + 左缘 1–2px realm 光
- 旧亮：无光、视觉退远
- 远岸：更小更淡小点光
- 冷墙：有墙无砖（勿先铺灰格占位）

## 禁止

奖杯 / 百分百进度条 / 通关戳 / 整墙闪烁 / 红叉锁 / 开炉永久金边

## 应改 UI 表面

残片墙格子、潮汐卡眉、锁态旁注、对错后「锻成」文案位；营地墙「读取中」落地亮态时按 C。
